# Rebecca's files

The diaries, logs and letters Rebecca reads on her day open the way RE1's
files do: full-screen pages she turns through, kept afterwards in the FILE
tab. This document says how RE1 stores a file, what is built, and what is
left.

The review page, with every page and its words and a rating for each file,
is at https://home.arpa/research/rebecca-files/.

## How RE1 stores a file

Checked on 2026-10-14 against `src/game/MainMenu.cpp` and the USA game's own
`item_m2/filem_*.pix`:

- **A file is an item.** Its file index is `itemId - 0x5F`, from 0 to 15. The
  collected flag is room flag `0x82 + index` (`src/game/BioCard.h:220`).
- **The pages of file `n` are one `.pix`**, named by `g_filemPixNames`
  (`0x004d2350`): `filem_l0.pix` for 0 through `filem_z0.pix` for 14, then
  `filem_00.pix` for 15.
- **A `.pix` is 16 little-endian offsets** (`0x40` bytes), one per page and
  one more for the end of the file. Each offset points at an LZW stream for
  `unpack_pakfile_` (`0x00425ab0`), the same packing as the room backgrounds.
  `pickup_unpack_list` (`0x004827c0`) unpacks page `n` by its offset.
- **A page is a 256x256 TIM at 4 bpp** with one 16-colour CLUT. The header
  places the CLUT at VRAM (0, 480) and the image at (0, 0), 64 VRAM words
  wide. RE1's own pages are light grey type on colour `0x0000`, which the
  PS1 draws as see-through, so the reader's black shows behind. The type
  carries the semi-transparency bit. The pictures, such as Barry's photo,
  do not.
- **The page count is not in the file.** The reader takes it from
  `g_itemMaxCounts` (`0x004d2620`) by file index: 4, 6, 11, 4, 2, 6, 7, 7, 10,
  5, 5, 4, 3, 3, 3, 4. The first page of every RE1 file is its title on black.

- **The reader shows a page's top 256x192 only**, at (24, 24) of the
  320x240 screen (`DAT_004d2888` in `MainMenu.cpp`). The bottom 64 rows of a
  256x256 page never show. RE1's own pages keep their text above row 192,
  eleven lines on a 16 pixel pitch from row 12. Her pages draw nothing from
  row 192 down (`SHOWN` in `pages.ts`, checked by `pages.test.ts`).
- **A file's name is its item name**, `message_item_name_lookup(0x5F +
  slot)`, in the FILE tab and in "... has been filed". The tab centres it on
  the scroll arrows at x `0x67`, using the offsets in `DAT_004d2630`.
- **The books are `g_keyItemListInit`** (`0x004d2a08`): per character, two
  books of eight file slots in a fixed order. A slot shows once its
  collected flag is set.
- **A file in a room is an `item_aot_set` with item `0x5F + slot`.** The
  command gives ids past the maps room action `0x0D`, which opens the reader
  on the spot (`set_room_event_flag`, then `menu_update_status_screen`).

## What is built

- `tools/rebecca/files/documents.ts` holds the ten documents, every word, page
  by page. Each one is written to the page count of the file slot it fills,
  so the reader needs no new count table. A text page holds eleven lines,
  or nine under the Umbrella letterhead. A line `~1` changes the writer's
  hand for the rest of the page.
- **Any free slot can take a document.** Her names, title positions and
  books are generated by slot (`engine.ts`), every slot has its own `.pix`
  name and collected flag (`0x82 + slot`), and the pickup is item
  `0x5F + slot`. Only the page count differs, so a document that needs more
  pages moves to a slot with that count. On 2026-10-15 seven documents
  moved to fit in 192 rows; slots 0, 7, 11, 13, 14 and 15 are free.
- `tools/rebecca/files/font.ts` is our own pixel font, drawn cell by cell.
- `tools/rebecca/files/pages.ts` draws the pages on four papers: a ruled
  notebook, a ledger with a time column, typed letter paper, and RE1's
  black. It also draws the art pages: the bunkhouse calendar, the mine map,
  the torn notice and the quarry rosters. It packs the pages as a `.pix`.
  Everything sits inside the top 256x192.
- `tools/rebecca/files/pages.test.ts` packs every document, unpacks it with
  the port of the game's decoder (`tools/harness/background.ts`), and checks
  that each page reads back pixel for pixel with the game's header. It also
  checks that no page, on its own paper or on RE1 black, draws from row 192
  down.
- `tools/rebecca/files/review.ts <outdir>` writes the review page. Each
  picture is the 256x192 the reader shows.

## How her mode uses it

- `src/game/RebFiles.cpp` is generated from `documents.ts` by
  `tools/rebecca/files/engine.ts` (`--check` fails when it is stale). It
  holds her names, her title positions and her books (`BOOKS` in
  `documents.ts`). Three hooks read it, each behind `g_bRebMode`:
  `pickup_screen_init_table`, the title draw in the book selector and
  `message_item_name_lookup`. Chris's and Jill's games keep RE1's tables.
- `tools/rebecca/build.ts` writes her pages to the overlay as
  `item_m2/filem_*.pix`, named by slot.
- `tools/rebecca/day/scripts.ts` turns the check a document names (its
  `check` field) into a file pickup with room-item flag `230 + its place in
  BOOKS`. The pickup sits on an empty item model slot, which
  `tools/rebecca/day/room.ts` adds to the end of every room's table. The
  cabin's logbook is written by hand the same way in `lookout/room.c`, so
  moving the logbook to another slot means changing its item there.
- `tools/harness/tests/files.ts` picks up all ten files in their rooms. It
  reads every page, compares each with the page the tools drew, and finds
  each file in the FILE tab. A shot must be closer to its own page than to
  any other page of the file. Screenshots:
  https://home.arpa/research/rebecca-files/game/.
